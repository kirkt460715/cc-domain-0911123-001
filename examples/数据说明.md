# 登记交换记录

records 中每行是一项首次登记，issuer 与 asset_id 组成业务键。effective_at 是登记生效时刻，received_at 是本地收到的时刻，均含 UTC 偏移。后四周有较慢投递的机构记录，cutoff 是演练观察点；演示导入全量历史，不替分析人选择训练范围。

导入器按收到顺序为各机构分配流序号，使用 received_at 驱动存储时钟。每个首次登记会重复投递一次以核对幂等，台账仍只存一条。分析可从 events 及历史查询读取真实 applied_at 与 commit_position。

这份按接收时间交错投递的数据可直接用于核对登记量分析：以 cutoff 为知识截止，`arrival.analyze` 只统计 applied_at 不晚于截止时点的首次登记，晚于截止的进入未成熟队列的“预计未到量”而非已知量；`arrival.hindcast` 的每个回看点同样只取那时已投影的记录，可验证模型估计相对“已知量即最终量”的误差，以及迟报机制改变的机构标记。
